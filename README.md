# Hyper Capsule — جزيرة مؤمن

تطبيق «جزيرة تفاعلية» لأندرويد/شاومي: حبة سوداء فوق في نص الشاشة بتكبر مع الإشعارات، وفيه تحكم موسيقى، حالة المكالمات، الشحن، ومؤقت داخلي.

## التشغيل
1. فعّل صلاحية «الظهور فوق التطبيقات» و«قراءة الإشعارات» من داخل التطبيق.
2. اضغط «تشغيل الجزيرة».
3. في شاومي: فعّل Autostart وخلي توفير البطارية «بدون قيود».

## البناء
كل push على main بيبني APK في GitHub Actions (workflow: Build APK)، والملف الناتج في Artifacts باسم hyper-capsule-apk.
